# Optimizer documentation

Canonical documentation for the Optimizer 4.0.0 release line.

## Documents

| File | Purpose |
|---|---|
| `ARCHITECTURE.md` | Optimizer responsibilities, main packages, runner contract, CLI boundary, release hygiene, and parameter validation. |
| `DEVELOPMENT.md` | Local checks, test workflow, release gate, and maintenance notes. |
| `RELEASE_4_0.md` | 4.0.0 release readiness checklist and acceptance notes. |

## Reading order

Start with `ARCHITECTURE.md` to understand the runner boundary. Use `DEVELOPMENT.md` while changing algorithms/reporting/storage and `RELEASE_4_0.md` before tagging or publishing.
